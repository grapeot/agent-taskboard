Local read-only task board placeholder

This is a scaffold placeholder page. It does not show live tasks, connect to a database, or listen to an event stream. Stored tasks and live updates are not implemented in this build.

Read-Only Projection Rules

Three screen states only: Not started, In progress, and Done. Done means accepted.

Badges on the last known state: Waiting for review, Failed, Blocked, and Stale. They are not a fourth screen state and they are not Done. Idle is not a status. A quiet process is not acceptance and is not failure.

Last reported time is displayed per task. A long gap means not updated; it does not mean done or failed.
